The widgets.base_classes sub-package#

The base_classes subpackage includes base classes and mix-ins for pydidas widgets, frames and windows.

class pydidas.widgets.base_classes.BaseFrame(**kwargs: Any)#

Bases: ConfigDictMixin, PydidasQsettingsMixin, WidgetFactoryMixIn, ParameterWidgetMixIn, QWidget

The BaseFrame is a subclassed QWidget and the base class for all Frames in pydidas.

The BaseFrame is instantiated lazily and the __init__ does not create all subwidgets. Instead, the following three methods are provided:

  • build_frame(): Build all widgets of the frame.

  • connect_signals(): Connect all the required signals for the frame.

  • finalize_ui(): Finalize the UI initialization.

The frame_activated slot is called when the frame is activated by the central widget. If the frame has not yet been built, it will finish the initialization by calling the three methods above.

The BaseFrame also provides a mechanism to export and restore the state of the frame, including parameter values and widget visibility. The export_state() method returns a dictionary with the frame’s state information, while the restore_state() method takes a dictionary with the state information and restores the frame’s state accordingly.

Restore the frame’s state from stored information.

The default implementation in the BaseFrame will update all Parameters (and associated widgets) and restore the visibility of all widgets. If the frame has not yet been built, the state information is only stored internally and not yet applied. It will be applied at the next frame activation.

Parameters:

state (dict) – A dictionary with ‘params’ and ‘visibility’ keys and the respective information for both.

class pydidas.widgets.base_classes.ParameterWidgetMixIn(**kwargs: Any)#

Bases: ParameterCollectionMixIn

The ParameterWidgetMixIn class includes methods which can be added to other classes to add functionality to create Parameter widgets and to have access to convenience functions for settings Parameter values.

create_param_widget(param: Parameter | str, **kwargs: Any) → None#

Add a name label and input widget for a specific parameter to the widget.

Parameters:

  • param (Parameter or str) – A Parameter class instance or the string refkey of a Parameter registered in .params.

  • **kwargs (Any) –

    Optional keyword arguments. Supported keys are:

    gridPostuple, optional

    The grid position in the layout. The default is (-1, 0, 1, 1)

    width_textfloat, optional

    The relative width of the text field for the Parameter name. The default is defined in pydidas.core.constants.PARAM_WIDGET_TEXT_WIDTH.

    width_unitfloat, optional

    The relative width of the text field for the Parameter unit. The default is defined in pydidas.core.constants.PARAM_WIDGET_UNIT_WIDTH.

    linebreakbool, optional

    Keyword to toggle a line break between the text label and the input widget. The default is False.

    parent_widgetQWidget or str or None, optional

    The widget to which the label is added. If a string, this picks up the calling class’s ._widgets dictionary and selects the string key’s value. The default is self.

    validatorQValidator or None, optional

    A custom validator applied to the I/O widget, if it supports one. The default is None.

    precisionint or None, optional

    Rounding precision for float Parameters. The default is defined in pydidas.core.constants.FLOAT_DISPLAY_ACCURACY.

    font_metric_width_factorint or None, optional

    Total widget width in multiples of the font metric character width. The default is FONT_METRIC_CONFIG_WIDTH.

    persistent_qsettings_refstr or None, optional

    QSettings reference key for persisting file-dialog directories across sessions. The default is None.

set_param_and_widget_value(key: str, value: Any, emit_signal: bool = True) → None#

Update a parameter value both in the Parameter and the widget.

This method will update the parameter referenced by <key> and update both the Parameter.value and the displayed widget entry.

Parameters:

  • value (Any) – The new parameter value. This must be of the same type as the Parameter datatype (or supported by a converter).

  • emit_signal (bool) – Flag to toggle emitting a changed signal after updating the value (if the value has changed). The default is True.

class pydidas.widgets.base_classes.WidgetFactoryMixIn(**kwargs: Any)#

Bases: object

A mixin class to allow easy widget creation in their host classes.

The WidgetFactoryMixIn class includes methods for easy adding of widgets to the layout. The create_something methods from the factories are called, and in addition, the layout and positions can be set.

Use the “gridPos” keyword to define the widget position in the parent’s layout.

add_any_widget(ref: str | None, widget_instance: QWidget, **kwargs: Any) → None#

Add any existing widget to the layout and apply settings to it.

Parameters:

  • ref (str or None) – The widget reference key.

  • widget_instance (QWidget) – The widget instance.

  • **kwargs (Any) – Any attributes supported by the specific QWidget with a setAttribute method are valid kwargs. In addition, ‘layout_kwargs’ is a valid key to pass a dictionary with attributes for the widget’s layout.

create_any_widget(ref: str | None, widget_class: type, *args: Any, **kwargs: Any) → None#

Create any widget with any settings and add it to the layout.

Note

Widgets must support generic args and kwargs arguments. This means that generic PyQt widgets cannot be created using this method. They can be added, however, using the add_any_widget method.

Parameters:

  • ref (str or None) – The reference name in the _widgets dictionary.

  • widget_class (type) – The class type of the widget.

  • *args (Any) – Any arguments for the widget creation.

  • **kwargs (Any) – Keyword arguments for the widget creation.

Raises:

TypeError – If the reference “ref” is not of type string.
